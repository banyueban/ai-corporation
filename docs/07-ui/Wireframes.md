## 13. 响应与收缩

1024px 宽度：

- App sidebar 收为图标栏；
- Workspace 右栏折叠为抽屉；
- 中央主内容保持至少 640px；
- Approval 内容保持单列；
- 任务列表和详情改为主从切换；
- 不隐藏暂停、审批和预算。
