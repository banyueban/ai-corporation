## 1. 需求与设计引用

- 用户确认的产品方向：AI Corporation 可以承接编码、图片、视频、文档、PPT 等任何 AI 能完成的任务；简单任务一名员工完成，复杂任务再按需多员工协作；
- 用户确认的体验原则：好用是第一原则；软件能自己处理的就自动处理；只有必要信息缺失或高风险操作才询问；
- 用户确认的透明原则：所有使用模型的地方都能查看实际模型输入、原始输出和工具过程，只有认证秘密隐藏；
- 用户确认的员工模型：每个员工都是独立 Agent，可以拥有自己的模型和技能；
- 用户确认采用 Pi，并已实际验证 Pi 支持现有 DeepSeek 模型；
- [产品重启说明](../../01-product/Product-Reboot.md)；
- [MVP Plan Milestone 7](../MVP-Plan.md#14-milestone-7pi-单员工可用闭环)；

## 2. 前置条件

- 原项目、GitHub 仓库、重启分支和旧路线恢复标签存在；
- 本机 Node 24 满足 Pi 要求，现有 pnpm workspace 可用；
- 应用内已有可用 Provider、API Key 和精确模型选择能力，真实 DeepSeek 资源只保存在本地，不进入 Git；
- 用户已确认首版采用 A+C：软件内置一个“文本整理与检查”技能，并允许导入包含 `SKILL.md` 的完整本地技能文件夹；
- Windows 在本机验证，macOS 由现有 CI 补充；自动模型测试使用本地受控服务，不能消耗或泄露真实 Key。

## 3. 包含范围

- 依赖并使用 `@earendil-works/pi-ai` 与 `@earendil-works/pi-agent-core`；
- 创建、保存、查看和选择一名员工；员工保存自己的名称、精确 Provider/model 和技能绑定；
- 内置“文本整理与检查”技能，内容可查看但不可删除；
- 用户选择包含 `SKILL.md` 的本地技能文件夹后，软件校验并复制整个文件夹到应用自己的技能目录；原目录移动或删除后不影响已导入技能；
- 再次导入同一技能时先展示文件变化，只有用户确认才更新应用内副本；导入技能首版只读，不能在软件内新建或编辑；
- 对话式任务输入，不经过旧 Goal Contract、Plan、DAG 或固定 Planner/Executor/Judge 团队；
- 一次真实 Pi Agent 运行，支持模型流式输出、停止和固定错误说明；
- 一个不会读取、写入或修改用户文件的安全演示工具，用于验证完整工具循环；
- 默认显示中文简洁进度，展开后显示完整模型输入、模型原始流、工具名称、工具输入、工具结果、耗时和错误；
- API Key、Authorization 和等价认证秘密始终隐藏；普通用户任务和模型内容不因脱敏规则被整体隐藏；
- 员工完成回答和自查后进入“等待用户验收”；用户确认后才显示“已完成”，用户不通过时保持未完成并可继续交代修改；
- 运行中取消、模型失败、工具失败、Renderer 重载和应用重启后的当前状态准确，不把未知或失败状态写成成功。

本任务贡献 Milestone 7 的首个单员工闭环。多员工、通用工作区工具、附件和专用内容工具仍未交付。

## 4. 非范围

- 图片生成、图片编辑、视频创作、视频剪辑、文档处理、PPT 或表格专用工具；
- 通用文件读取、写入、删除或命令执行；
- 附件上传、解析和多模态输入；
- 在软件内新建或编辑技能；只支持查看内置技能和导入技能内容；
- 旧 Goal、Plan、Task、Run 数据迁移或删除；
- 恢复旧 M3-TU-04 的严格 JSON 候选输出和复杂状态机；
- 公开发布、代码签名、付费动作或对外发送消息。

## 5. 简化与后续增强

- `DE-011`：首任务只做一名员工，多员工分工和委派后续补齐；

## 6. 依赖与接口

- Renderer 通过版本化 Preload API 提交用户动作，不直接获得 Provider API Key，也不直接调用模型或 Node API；
- Electron Main 读取应用内保存的 Provider 和 Key，创建 Pi model 与 Agent；员工绑定精确 Provider/model，不修改 Provider 默认模型；
- Pi 事件被保存为可按顺序查看的运行记录；界面显示原始业务内容，但持久化和日志必须排除 API Key、Authorization 及等价认证秘密；
- 导入技能使用应用管理的独立副本；技能标识来自经过校验的技能内容，不信任来源目录名；导入路径不得成为运行时依赖；
- 再次导入同一技能时先计算新增、修改和删除文件列表；用户确认前不覆盖当前副本，确认更新必须整体成功或保持旧副本；
- 工具只通过明确注册的固定接口调用；首个演示工具没有文件、进程、网络付费或对外发送副作用；
- 取消必须传递到当前模型/工具运行；取消后的迟到内容不能把任务改成完成；
- 用户验收是独立动作，Pi 或员工不能替用户调用“验收通过”。

共享冲突区：根依赖锁、Desktop Main/Preload API、SQLite migration、Provider/Key 读取边界、导航、设计系统、安装包和 `PROJECT_STATUS.md`。本任务串行修改这些文件，不同时推进旧 M3 路线。

- 自动测试使用 `M7-TU-01-<random>` 的临时 userData、SQLite、员工、任务和动态本地服务端口；
- 每个测试自行创建数据并释放模型连接、工具执行、计时器和 Electron 进程，不依赖旧 M3 数据；
- 测试 Key 为明显的假值，真实 DeepSeek Key 只由正式应用内已有 Provider 使用；
