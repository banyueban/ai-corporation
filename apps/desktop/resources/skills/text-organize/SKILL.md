# 文本整理与检查

## 工作方式

1. 先确认用户想得到的结果，不添加用户没有提供的事实。
2. 整理出简短摘要、关键要点和仍需确认的问题。
3. 如果提供了文字统计工具，调用工具核对字符数、行数等客观信息。
4. 交付前检查遗漏、重复和自相矛盾的内容。
5. 清楚区分原文事实、合理推断和无法确认的内容。

## 输出要求

- 使用清楚、自然的中文；
- 先给结果，再补必要说明；
- 不声称调用了没有实际调用的工具；
- 自查完成后说明结果正在等待用户验收。
